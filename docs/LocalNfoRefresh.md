# 本地 NFO 标题与简介更新

在 MoviePilot V3 插件市场的插件仓库设置中添加 `https://github.com/mapeili521/MoviePilot-Plugins`，刷新市场并安装。需要支持 V3 插件 SDK 一次性调度接口的宿主。

1. 媒体根目录填 MP 容器内可见的绝对路径，一行一个。首次选一部剧的目录，包含 tvshow.nfo 和各季子目录；写入时该挂载需要可写。
2. 标题和简介分别选择修复占位、只补空缺、跟随覆盖或保留。缺少有效远端内容时保留本地值。默认语言 zh-CN。没有宿主 TMDB API Key 时可在配置中填写自己的 TMDB 凭据。
3. 选“仅预览”并保存，在详情页查看路径和字段前后值。选“立即写入”会处理本批；定时写入另有独立开关。默认北京时间每天 04:30，每轮 100 个媒体文件。调大上限可完成较大范围的一次性复查。
4. 正式写入前按批次备份到插件数据目录。选择“撤销最近批次”恢复原文件；发现后续编辑则跳过。请保留 MP 的持久化配置目录。当前版本不会自动清理旧备份。
5. 可选开启 MP 通知。Emby 定向刷新需提供服务器 API 地址、API Key，并在具体文件映射中指定 emby_id。详情页显示刷新请求结果，客户端呈现取决于媒体库的 NFO 读取配置。

电影使用 movie.nfo 或媒体同名 NFO 的 TMDB ID。剧集使用 tvshow.nfo 的剧集 TMDB ID，加上文件名或分集 NFO 的季集号。仅在启用创建且身份明确时生成新 NFO。手动映射示例：

```json
{
  "/media/示例/Season 01/示例.S01E19.strm": {
    "id": 123456,
    "season": 1,
    "episode": 19,
    "emby_id": "789"
  }
}
```

id 为 TMDB 电影或整部剧 ID，emby_id 为 Emby 内该电影或该集的条目 ID。请替换示例值。复查会枚举目录，网络查询按到期队列和每轮上限执行。STRM 仅按文件名定位旁边的 NFO。建议首次用副本试跑并检查 Emby 显示。
